### 🐧➕🪟 [linwin](https://github.com/2Deathadder/linwin) — Windows 10 en dual-boot depuis Linux, sans clé USB

[![linwin](https://raw.githubusercontent.com/2Deathadder/linwin/main/docs/og.png)](https://2deathadder.github.io/linwin/)

**linwin** installe Windows 10 à côté de Linux **sans clé USB** : il fait la place sur le disque, copie
l'installeur sur une partition temporaire, installe Windows **sans intervention**, ajoute les pilotes
(Intel RST/VMD, Wi-Fi, Ethernet) et le met dans le menu de **GRUB, systemd-boot, Limine ou rEFInd**.
Libre (GPL-3.0), pour toutes les distributions.

- 🌐 Site : [2deathadder.github.io/linwin](https://2deathadder.github.io/linwin/) · [English](https://2deathadder.github.io/linwin/en/)
- 📖 Guides : [dual-boot sans clé USB](https://2deathadder.github.io/linwin/guides/dual-boot-sans-cle-usb/) ·
  [Ubuntu, Mint, Debian](https://2deathadder.github.io/linwin/guides/ubuntu-mint-debian/) ·
  [SSD invisible (Intel VMD/RST)](https://2deathadder.github.io/linwin/guides/intel-vmd-rst-ssd-invisible/) ·
  [Windows dans GRUB/systemd-boot/Limine](https://2deathadder.github.io/linwin/guides/ajouter-windows-grub-systemd-boot-limine/)
- ⬇️ [Télécharger la dernière version](https://github.com/2Deathadder/linwin/releases/latest)

> **English** — [linwin](https://github.com/2Deathadder/linwin) installs Windows 10 as a dual-boot from Linux
> without a USB drive: unattended setup, drivers included, GRUB/systemd-boot/Limine support, any distribution.

### 🎛️ [Coreboard](https://github.com/2Deathadder/coreboard) — le centre de contrôle matériel natif pour Linux

[![Coreboard](https://raw.githubusercontent.com/2Deathadder/coreboard/master/docs/img/social-preview.png)](https://2deathadder.github.io/coreboard/)

**Coreboard** réunit dans une seule application ce qu'Armoury Crate ou MSI Center proposent sous Windows :
**modes de performance**, réglages du **processeur et du GPU**, **fréquence d'écran**, luminosité, **éclairage RGB**,
**scénarios** par application, **macros** et **jeux Windows** via Proton-GE. Écrit en C et GTK4, pour Hyprland,
GNOME, KDE, Sway et X11. Libre (GPL-3.0), pour toutes les distributions.

- 🌐 Site : [2deathadder.github.io/coreboard](https://2deathadder.github.io/coreboard/) · [English](https://2deathadder.github.io/coreboard/en/)
- 📦 Installation : [Arch, Debian/Ubuntu, Fedora, openSUSE](https://2deathadder.github.io/coreboard/#installation)
- ⬇️ [Télécharger la dernière version](https://github.com/2Deathadder/coreboard/releases/latest)

> **English** — [Coreboard](https://github.com/2Deathadder/coreboard) is a native hardware control center for Linux,
> an Armoury Crate alternative: performance modes, CPU/GPU tuning, display, RGB lighting, per-app scenarios, macros
> and Windows games through Proton-GE. GTK4, any distribution, any desktop.
