### 🐧➕🪟 [linwin](https://github.com/2Deathadder/linwin) — Windows 10 en dual-boot depuis Linux, sans clé USB

[![linwin](https://raw.githubusercontent.com/2Deathadder/linwin/main/docs/og.png)](https://2deathadder.github.io/linwin/)

**linwin** installe Windows 10 à côté de Linux **sans clé USB** : il fait la place sur le disque, copie
l'installeur sur une partition temporaire, installe Windows **sans intervention**, ajoute les pilotes
(Intel RST/VMD, Wi-Fi, Ethernet) et le met dans le menu de **GRUB, systemd-boot, Limine ou rEFInd**.
Libre (GPL-3.0), pour toutes les distributions.
